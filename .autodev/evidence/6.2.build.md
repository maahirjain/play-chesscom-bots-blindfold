## What was built

**`exporter.js`** (extended): pure `buildEventsJsonl({events})`.

1. **Ordering:** events sorted by `appendSeq` ascending (numeric). The sort
   is stable; `appendSeq` is unique per the 2.4 sequence counter.
2. **Serialization:** one `JSON.stringify(event)` per line, joined by
   `'\n'`, with a trailing `'\n'` (standard JSONL). Empty input → empty
   string.
3. **Verbatim passthrough:** every key/value copied exactly. The builder
   adds no keys, removes no keys, reorders no keys.
4. **No computed metrics:** the builder computes nothing — no durations,
   counts, rates, or wall-clock derivations.
5. **No position filtering:** `move_confirmed` events gain no FEN/SAN/PGN;
   legitimate stored positions (`game_started` FEN, 1.4.4 recovery
   checkpoints) pass through verbatim. "No duplication" is a preserved
   property, not a filter.

**Malformed input (fail-closed):**
- `events` not an array → `TypeError`.
- Non-object element → `TypeError` naming the index.
- `appendSeq` null/non-integer/negative → `TypeError` naming the
  `eventId` and index.
- Duplicate `appendSeq` → `TypeError` (never silently reordered).

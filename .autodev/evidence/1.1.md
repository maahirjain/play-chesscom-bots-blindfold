## Implementation summary

- `session_identity.js` (new): `SCHEMA_VERSION="1.0.0"` (data-contract
  version, frozen), `SESSION_CATEGORIES=['baseline','training','evaluation']`
  (frozen), `UUID_V4_RE` (frozen), `newSessionId()`/`newGameId()` via
  `crypto.randomUUID()` (throws if unavailable — no Math.random fallback),
  `isUuidV4`, `isSessionCategory`, `normalizeProtocolVersion`

  `createSessionMetadata({extensionVersion, sessionCategory, protocolVersion})`

  detection would misrepresent evidence), `addGameToSession(metadata, gameId?)`
  (pure, returns new record; duplicate explicit gameId throws Error — see
  DECISIONS.md). Returned records and gameIds arrays are frozen (append-only).

- No existing files modified. No PLAN.md changes.

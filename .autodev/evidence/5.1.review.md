## The four deviations — all faithful, none weaken PLAN

1. **Start-abort rule refined** (abort only when the start-streams response
   has no `streams` object). **Verified faithful against
   `stream_starter.js`:** guard rejections (`no-session`,
   `start-in-progress`, `already-started`, `internal-error`) return
   `{ok:false}` with **no** `streams` object, while per-stream results return
   top-level `ok` = all-three-ok **with** a `streams` object. The contract's
   parenthetical "({ok:false} at top level)" was imprecise: taken literally,
   a single failed stream would abort Start, defeating PLAN §4.6's failure
   isolation. The builder's rule is the reading PLAN requires. AC4's
   headline ("Per-stream start failures do not abort Start") holds.
2. **`classifyStreamStatus(status, startResult)`** — faithful (see AC2).
   It closes the denied-screen-masquerading-as-`off-idle` hole the contract
   identified; it adds an adverse fact, never removes one — no new
   smoothing path.
3. **`flushTimedOut` is per-stream** — factual. `finalizer.js:820` sets
   `perStream[kind].flushTimedOut`; there is no top-level field. 5.1 hands
   the response object through untouched (V2 proves deep-equal), so the
   5.10 seam receives everything the audit carry-forward requires.
4. **V2 harness origin routing** — test-only and documented; the actual code
   sends `recorder-ensure` from the offscreen document with the SW answering
   (harness lines 151/167/179), matching production's responding side.

## Masquerade walk (adversarial)

No adverse fact yields `recording-healthy`: terminal chunk states,
`lastRecorderError`, `lastDiscontinuity`, ended/muted tracks, and
`start-failed` all force degraded/failed states. Inconsistent input
(`finalizedAtUtc` set while `recording`) fails safe to degraded with the
inconsistency itself as a fact. Unknown lifecycle → `unknown` (never
green). A kind absent from the status response → `unknown`, not idle
("absence of evidence is not evidence of idleness"). No `"ready"`
vocabulary anywhere in the module (only the comment "is NOT defined
here"); no auto-stop on game end (no game-end listeners); no 5.2–5.10 UI
smuggled in.

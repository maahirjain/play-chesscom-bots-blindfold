## Implementation

**`chess_utils.js`:**
- 3.2-owned event vocabulary: `MOVE_ATTEMPT_EVENT_TYPE`,
  `MOVE_DISPATCH_STARTED_EVENT_TYPE`, `MOVE_DISPATCH_FAILED_EVENT_TYPE`,
  `MOVE_ATTEMPT_MATCHED_EVENT_TYPE`, `MOVE_ATTEMPT_UNCONFIRMED_EVENT_TYPE`
  (`event_envelope.js` untouched).
- `DISPATCH_FAILURE_REASONS` (frozen): `move_unparsable`,
  `board_not_found`, `square_coordinates_failed`,
  `promotion_window_timeout`, `promotion_choice_missing`.
- `makeMoveOnBoard` returns `true` on success, otherwise the specific
  reason (was: bare `false`). `handlePromotionIfNeeded` distinguishes
  window-timeout vs missing-choice. `BlindfoldSession.makeMoveOnBoard`
  exported for testability (content.js keeps the module-local call).
- Seven exact-keys payload/refs validators
  (`requireValidMoveAttemptPayload`, etc.), exposed on BlindfoldSession.
  TypeError = wrong type/shape; RangeError = bad domain value.
- `createFirstEditCapture(nowFn)`: first-write-wins timestamp + submit
  snapshot/reset; only the timestamp retained.
- `createAttemptTracker({emitEvent, getSessionId, getGameId,
  unconfirmedTimeoutMs=30000, setTimeoutFn, clearTimeoutFn})`: DOM-free
  pending → matched | unconfirmed | terminal-at-birth lifecycle.
  Emission gated on non-empty sessionId AND gameId (thunks; pre-§5
  inert). FIFO matching on (from, to, promotion); null eventIds never
  link. Timeout / `handleGameReset` / `handlePageHide` (best-effort, never
  throws) mark pending attempts unconfirmed. Illegal-at-submit,
  unparsable, and dispatch-failed attempts are terminal at birth —
  absence of confirmation is never labeled illegal (3.2.6).

**`content.js`** (surgical):
- Attempt tracker + first-edit capture instantiated (3.2.7 limitation
  documented in a comment).
- `input` listener captures first-edit time (programmatic clears don't
  fire `input`).
- Enter handler is now `async`: verbatim `rawText` captured before
  normalize/clear (3.2.2); UX (borders, sounds) unchanged; attempt
  submitted with validation outcome; normalized string never stored
  (3.2.3); legal attempts → `noteDispatchStarted`, awaited
  `makeMoveOnBoard`, `noteDispatchFailed` on failure (3.2.4).
- `observeMoves` callback calls `noteConfirmedMoves(result.confirmed)`
  after the history tracker (3.2.5 — link only after observed acceptance).
- `onGameReset` stub also calls `attemptTracker.handleGameReset()`.
- `pagehide` listener calls `handlePageHide()` (2.7 philosophy: never
  throws, never flushes).

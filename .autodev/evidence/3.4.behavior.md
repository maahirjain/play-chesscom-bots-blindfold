## Per-AC results (each re-checked against code, not trusted from prior reports)

- **AC1 (3.4.1): PASS.** Every utterance through the tracker choke point
  gets a uuid-v4 `utteranceId` (`newUtteranceId()` per `speak()` call;
  `crypto.randomUUID()` via 1.3's `newEventId`, no weak fallback).
  Link refs built only in `normalizeLink` (sounds.js:641) — the single
  refs-construction site — producing the sparse single-key form
  `{moveEventId}` xor `{helpRequestEventId}`; `requireValidUtteranceStartedRefs`
  enforces exactly-one-key + uuid-v4 value (sounds.js:467-483), so no
  null ref value can reach the sender's `requireRefs`. content.js
  threads links at all sites: `sayMove` → `{trigger:'move', moveEventId:
  m.eventId}` (content.js:127), `announceResultIfOver` →
  `{trigger:'game-result', moveEventId}` of the terminal confirmed move
  (content.js:136), w/m/z/i/s help handlers → `helpLink(eventId)`
  (content.js:281-336). Null links → unlinked utterance (spoken, no
  `utterance_started`) — the contract's §2.2 design.
- **AC2 (3.4.2): PASS.** `utterance_started` emitted at dispatch (before
  the speak primitive, sounds.js:716-740); `onend`/`onerror` attached
  per utterance → `utterance_ended` (sounds.js:706-715). No `onstart`
  handler exists anywhere in sounds.js — matches the contract's
  documented decision (start recorded at dispatch; callback firing not
  separately observable). Started payload carries exactly the §2.3 keys
  including `speechLogicVersion: '1'` and per-utterance
  rate/pitch/volume/voiceName.
- **AC3 (3.4.3): PASS.** `cancelRequested(source)` records
  `utterance_cancel_requested` per in-flight utterance and sets a
  per-entry flag (sounds.js:756-773). Correlation is by flag, never by
  callback name: `onend` → `'cancelled'` only if the flag was set, else
  `'completed'`; `onerror` without flag → `'error'` with the raw
  `ev.error` string, with flag → `'cancelled'` (sounds.js:706-715).
  `speakFullMoveList`'s timestamp abandonment performs no `cancel()`
  call and records nothing — documented. Residual (review NOTE-1):
  if the browser fires neither callback, the in-flight entry leaks and
  a later cancel could emit a spurious `cancel_requested` — rare,
  browser-quirk-gated, noted not blocking.
- **AC4 (3.4.4): PASS.** `text: (typeof o.saveText === 'string') ?
  o.saveText : null` (sounds.js:732). Grep confirms exactly one

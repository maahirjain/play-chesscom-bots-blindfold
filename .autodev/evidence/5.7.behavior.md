### AC1 — static no-path-to-stop pin (3 tests)

1. **content.js never references onStopClick.** Reads content.js source,
   strips comments, asserts no `\bonStopClick\b`. Meaningful: the
   game-end observer (content.js's move observer calling
   `recordChessRulesEnded`) lives in content.js; if anyone wired a
   game-end → stop path there, this fails.

2. **session_controls.js calls onStopClick() exactly once.** Counts
   `onStopClick()` call sites excluding the definition (negative
   lookbehind `(?<!function )`), asserts exactly 1, and asserts the
   400 chars preceding the call site contain no game-end terms.
   Meaningful: a new auto-stop wiring would add a call site or sit in
   a game-end context; either fails this test.

3. **recordGameEnded body has no stop references.** Extracts
   `recordGameEnded`'s body by brace matching (not substring search),
   asserts no `onStopClick`, `stop-streams`, `MSG_STOP_STREAMS`, or
   `channelCall`. The most precise of the three — immune to comment
   smuggling (comments stripped first) and to false positives from
   other functions' bodies.

These are static pins for a negative invariant ("no path exists"),
which is the correct mechanism — a behavioral test alone cannot prove
the absence of a path. None is vacuous: each names a concrete
violation that would make it fail.

## What was built

**`exporter.js`** (extended): pure `buildMediaSyncJson({manifestRecords, clockAnchors, stopVerdict, segmentFiles, chunkStats, nowUtcIso})`.

1. **Schema:** exact §3 schema with stable key order. Per-segment:
   `segmentId`, `streamKind`, `segmentNumber`, `filename`, `format`,
   `fileExtension`, `finalized`, `finalizedAtUtc`, `createdAtUtc`,
   `streamStartedAtUtc`, `streamStartedAtMonotonicMs`, `clockSegmentId`,
   `clockAnchor`, `mediaStartWallUtcMs`, `chunkCount`,
   `chunksAfterFinalize`, `gaps`. Top-level: `segments`, `knownGaps`,
   `stopVerdict`, `exportedAtUtc`.

2. **The ONE computed value:** `mediaStartWallUtcMs` via the timecode.js
   canonical formula `anchor.utcEpochMs + (streamStartedAtMonotonicMs -
   anchor.monotonicMs)`. Null when anchor missing or inputs unusable.
   Never rounded (rounding is lossy; analysis code rounds).

3. **Known gaps (two layers):**
   - Session-level `knownGaps`: 5.10's warning vocabulary verbatim
     (`<kind>-flush-timed-out`, `<N>-events-undelivered`,
     `<kind>-failed:<error>`, `<kind>:missing-stream-result`,
     `stop-response-malformed`, `flush-result-unknown`). Absent verdict →
     `['stop-verdict-unavailable']`.
   - Per-segment `gaps`: fixed vocabulary (`unfinalized`,
     `flush-timed-out`, `stream-failed`, `chunks-after-finalize:<N>`,
     `missing-clock-anchor`, `missing-stream-start-time`).

4. **Deterministic ordering:** kind (microphone→screen→webcam) →
   segmentNumber (nulls last) → createdAtUtc → segmentId. Byte-stable for 6.7.

5. **Fail-closed:** `'failed'` verdict → plain `Error` (session-not-complete).
   Malformed inputs → `TypeError`. Unfinalized segments listed, never omitted.

## Open questions resolved

1. **flush-timeout attribution:** kind-level is the honest default — applied
   to every segment of that kind (labeled by kind key, not misattributed
   to a single segment). The finalizer records don't provide
   segment-level precision.
2. **Offset precision:** not rounded. The golden test pins `1000500.5`
   (fractional milliseconds preserved).

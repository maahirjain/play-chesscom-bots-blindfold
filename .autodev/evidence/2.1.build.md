## Notable harness finding (documented, no contract impact)

Puppeteer launches Chrome with `--disable-extensions` in its default args,
which silently neuters `--load-extension`: no targets appear, no content
scripts inject, and no errors surface. This initially made AC5 look
impossible. The fix is `ignoreDefaultArgs: ['--disable-extensions']` in the
harness launch options (applied in `sw-load.js`). Verified with probe
extensions: with the flag ignored, a comment-only SW registers a target and
a content script injects (`data-cs-probe` side effect observed). Future
V2/V3 extension-load harnesses in `~/workspace/tools/ext-verify/` must use
this option. Consider recording this in `.autodev/DECISIONS.md`.

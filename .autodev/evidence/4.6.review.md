   4.13/§5, not 4.6.

   auto-grant), so `picker-unavailable` is V1-pinned only; real
   headed-device picker behavior is AC12/§7 territory. No fabricated
   workaround exists in the code — the degradation path is honest.

   superseded by the 4.6 §0 amendment. Evidence files are historical;
   the section-4 auditor should confirm 4.10/4.13 apply the amendment

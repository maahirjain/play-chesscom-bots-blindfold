## What was built

**`device_selection.js` (new)** — DOM-free `createDeviceSelector({kind})` factory
(house convention: dependency-free → guarded `BlindfoldSession` global →
IIFE `'use strict'` → Node shim). 4.2 instantiates `kind:'audioinput'`;
4.4 will reuse it for `'videoinput'` (camera event types/keys already
wired). Injected `mediaDevices`, `storage` (chrome.storage.local-shaped),
`permissions`, `emitEvent`, `getSessionId`/`getGameId` thunks, clock.

- `listDevices()` → `{ok, devices:[{deviceId,label,kind}]}`; empty labels
  → `null` (Chrome withholds labels pre-grant; honest null, never
  fabricated). Empty device list is an honest observation, not an error.
- `select(deviceId)` → validates against the last enumeration (on-demand
  enumerate when uncached); unknown → `RangeError` (channel maps to
  `{ok:false, error:'unknown-device'}`); known → persists, emits
  `microphone_device_selected` with `source:'user'`. Works pre-session as
  a setting; only the event is inert (3.x precedent).
- `requestPermission()` → `getUserMedia` probe with
  `{deviceId:{exact:selection}}` or `{audio:true}`; **every probe track is
  stopped before resolving — no open mic stream is ever retained** (4.6
  re-acquires at Start). `NotAllowedError`/`SecurityError` → `'denied'`;
  `NotFoundError`/`OverconstrainedError` → selection invalidated (cleared,
  stored key dropped, `source:'invalidated'` event); else `'unknown'`
  with the raw `errorName`. Concurrent probes share the in-flight request
  (contract §6.5, builder's choice — documented).
- `queryPermission()` → advisory `permissions.query`; emits on change with
  `source:'query'`; absence skipped silently. **A probe-observed `'denied'`
  persists until a later probe succeeds** (contract §2.3 explicit) — the
  advisory query never clears it.
- `restoreOnBoot()` → reads `blindfold.micDeviceId.v1`; present in a fresh
  enumeration → selection restored (`source:'restored'`); absent → stays
  `null`, no event, no silent default. Storage failure → honest
  `{restored:false, reason:'storage-unavailable'}`.
- `announceSelectionForSession()` → once per session, announces the
  current selection with its ACTUAL source (`'user'` vs `'restored'`,
  never relabeled); null announces nothing.
- `getState()` → `{ok, selection, permissionState, devicesEnumeratedAt}`
  (the queryable state 4.14/5.6 read).
- Two 4.2-owned event types with exact-keys validators (exported):
  `microphone_permission_changed`
  `{permissionState, source:'query'|'request', errorName}` and
  `microphone_device_selected` `{deviceId, label, source}`.
  `event_envelope.js` untouched.

**`recorder.js` (+`recorder.html`)** — instantiates the mic selector;
routes the five channel messages (`recorder-set-session`,
`mic-list-devices`, `mic-select`, `mic-request-permission`,
`mic-get-state`) on 4.1's `{kind:'recorder', msg, v:1}` envelope with
failure isolation (3.2 SF-1: every handler answers `{ok:false, error}`,
never throws, never drops a liveness pong). New session-gated event
emitter: builds envelopes via `event_envelope.js` (lazy `clock_anchor`
per session, `sourceContext:'recording_context'`, per-document sourceSeq)
and sends `{kind:'event', event}` **directly to the existing writer
intake** — no relay, no new pipeline (4.1 §3). Sends are ack-observed
(console.warn on missing/negative ack, never thrown). `recorder.html`
loads `event_envelope.js` + `device_selection.js` before `recorder.js`.

**Tests** — `tests/device_selection.test.js` (43 tests, AC1–AC8); 13

## Deviations (all documented here + DECISIONS.md §4.2)

1. **Persistence backend: document `localStorage`, not `chrome.storage.local`.**
   The contract specified chrome.storage.local-shaped persistence with "no
   manifest changes" — but V2 proved **offscreen documents expose only
   `chrome.runtime`**: `chrome.storage` is `undefined` there even with the
   `"storage"` manifest permission (verified empirically in the live
   document; the SW does have it). The selection persists in the offscreen
   document's `localStorage` under the same `blindfold.micDeviceId.v1`
   key (same extension origin; §5's popup reads the same store). No
   manifest change, no event-DB schema change. The selector's injected
   storage interface is unchanged — only the production wiring differs.
   (An earlier build briefly added the `"storage"` permission; reverted —
   it cannot work in the offscreen document.)
2. **Selection-source honesty.** `announceSelectionForSession` emits the
   selection's ACTUAL source at session activation. A pre-session *user*
   selection announced as `'restored'` would be a lie; the selector tracks
   `selectionSource` (`'user'`/`'restored'`) and never relabels. (Caught by
   a V1 smoke test during the build.)
3. **Restore/session race fix.** If `recorder-set-session` arrives before
   the async boot-restore completes, the restored selection was never
   announced (V2 caught this as a flaky AC11). `restoreOnBoot` completion
   now also calls the announcer; the per-session dedup makes the
   set-session/restore pair idempotent in either order.
4. **Probe-denied persistence vs advisory query.** The contract (§2.3)
   says an observed denial "persists as the queryable permission state
   until a later probe succeeds" — V2 caught `getState`'s advisory query
   overwriting it with `'prompt'`. The query no longer clears a
   probe-observed `'denied'` (it can still report revocations on every
   other state).
5. **AC10 denial mechanism.** CDP `Browser.setPermission` was tried
   first: the setting applied (`permissions.query` → `'denied'`) but
   `--use-fake-ui-for-media-stream` bypasses the content setting for
   `getUserMedia`, so no denial materialized. The honest V2 denial is a
   second browser without the fake-UI flag, where headless Chrome
   auto-dismisses the prompt → genuine `NotAllowedError`.
6. **AC9 "no live mic retained".** No extension API enumerates live
   MediaStreams from outside the document, so V2 cannot observe
   track-stopping directly; it is V1-pinned with `stop()` spies
   (every probe track stopped, selector retains no stream reference).
   Documented, not fabricated.

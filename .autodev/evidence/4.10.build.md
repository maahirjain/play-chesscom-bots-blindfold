## What was implemented (per `.autodev/evidence/4.10.contract.md`, 11 ACs)

**New module `clock_link.js`** (DOM-free, repo module pattern:
dependency-free classic script → guarded `BlindfoldSession` global →
IIFE `'use strict'` → Node `module.exports` shim). Exposes
`createClockLink()` → `{linkClockSegment}` and `linkClockSegment`
directly. `linkClockSegment({segmentId, getAnchor})` → `{clockSegmentId}`:

- Forces the lazy anchor capture through the injected `getAnchor`
  thunk (recorder.js's `ensureAnchor` in production) — honest, because
  the anchor describes the document's already-running clock.
- Identity-only: reads `anchor.segmentId` and nothing else. No
  `deriveWallUtcMs`, no offset arithmetic, no `timecodeMs`
  interpretation (4.12 owns all of that).
- **Never throws**: missing/throwing `getAnchor`, malformed anchor,
  non-uuid `segmentId` → `{clockSegmentId: null}`. Unknown is null;
  linking can never fail a stream (the 4.6/4.7/4.8/4.9 precedent).

**Wiring:**

- `stream_starter.js`: new `clockLink` + `getAnchor` opts (injected for
  tests); `readClockLink()` resolves lazily from the shared namespace
  at call time (the `readAudioPolicy` precedent — `createAudioPolicy`
  pattern); `linkStreamClock(segmentId)` wraps the call so any failure
  → `null`. Called in the manifest-write stage (the same stage 4.6/4.7
  own); `clockSegmentId` written into the record and carried on the
  `recorder-start-streams` response (4.6/4.7 precedent).
- `format_support.js`: `MANIFEST_KEYS` deliberately widened **15 → 16**
  (`clockSegmentId`, `// 4.10-owned:` comment); `requireValidManifestRecord`
  validates it as null-or-uuid-v4; `recordSegmentFormat` accepts it
  (defaults null); new additive `getManifestRecord(segmentId)` read
  (the store's keyPath IS `segmentId` — no new index, no schema
  change, `DB_VERSION` stays 2).
- `recorder.js`: lazy `getClockLink()` (the `getAudioPolicy` precedent;
  absence is a wiring defect → plain `Error`); passed as
  `clockLink: getClockLink()` plus `getAnchor: ensureAnchor` into
  `createStreamStarter`; exposed on the test seam as the **4.13 seam**
  (4.13 calls `getClockLink().linkClockSegment` for each
  post-discontinuity segmentId it mints — 4.10 owns all linking).
  `recorder.js` still references no media-capture APIs (4.1 boundary).
- `recorder.html`: loads `clock_link.js` (after `audio_policy.js`,
  before `stream_starter.js`).
- `.autodev/DECISIONS.md`: new `## 4.10 clock-segment linking` section
  (link model, forced capture, identity-only, gap/restart semantics,
  4.13 seam, PLAN reading note for the section-4 auditor).

No new event types, no new channel messages, no manifest writes outside

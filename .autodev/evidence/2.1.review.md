## What was checked adversarially

- **sw.js content**: read in full. It is comments plus `'use strict';` only.
  No `indexedDB`, `chrome.*`, listeners, `fetch`, `importScripts`, logging,
  or any other functional code. The test's comment-stripping assertion
  (stripped remainder deep-equals exactly `["'use strict';"]`) is the
  strongest possible static form of this check — it cannot be fooled by
  moving code into comments' neighbors.
- **manifest.json diff**: `git diff HEAD` shows exactly the 3-line
  `"background": { "service_worker": "sw.js" }` insertion. `content_scripts`
  and `web_accessible_resources` blocks are byte-identical; no `permissions`,
  `host_permissions`, `content_security_policy`, or version bump.
- **Smallest form**: `"service_worker": "sw.js"` alone is the minimal MV3
  entry (`"persistent"` is MV2-invalid; `"type": "module"` unnecessary —
  the contract pre-rejected it and AC5 now proves a classic worker loads).
- **Scope vs PLAN §2**: nothing from 2.2–2.9 is preempted. The entry does
  not lock in a message protocol, storage schema, or module format; a future
  task can still add `"type": "module"` if it demonstrates a need. The
  stub's "intentionally absent" header is an explicit anti-gold-plating
  guardrail, not a design constraint.
- **Builder file hygiene**: `git status` shows the builder touched exactly
  `manifest.json`, `sw.js`, `tests/manifest_sw.test.js`, plus evidence files.
  (`.autodev/DECISIONS.md` was also modified, by the coordinator, to record
  the puppeteer `--disable-extensions` harness finding — disclosed in the
  build report, appropriate lane, no sensitive content.)
- **AC5 harness soundness**: `sw-load.js` cannot pass vacuously.
  `browser.waitForTarget(t => t.type() === 'service_worker' && /\/sw\.js$/.test(t.url()), {timeout: 20000})`
  fails the run (nonzero exit) if no worker registers — this is the primary
  proof, and it is real: this review observed
  `chrome-extension://leondjonaopkphagdgghahffoncbmckf/sw.js` register.
  The stderr scan is secondary/complementary (a load failure would also
  prevent SW registration). `ignoreDefaultArgs: ['--disable-extensions']`
  is the correct fix for puppeteer neutering `--load-extension`.
- **AC7 deferral**: honest. The managed browser cannot load unpacked
  extensions (`.autodev/DECISIONS.md` decision 3); real-device load is
  genuinely V4-only.
- **REGRESSIONS.md**: no invariant violated; the gameplay baseline
  (hotkeys, move input, speech, piece-set storage) is untouched.

## Findings

- **NOTE-1**: `tests/manifest_sw.test.js` shells out to `git show
  HEAD:manifest.json` for the AC4/AC6 byte-comparisons. This fails if the
  suite is ever run outside a git checkout (e.g. an exported tarball). The
  repo's entire workflow is git-based, so this is acceptable — but if tests
  are ever packaged without `.git`, these three assertions need a fallback.
- **NOTE-2**: `sw-load.js` attaches the browser-stderr listener after
  `puppeteer.launch()` resolves, so very early startup stderr could be
  missed. Harmless in practice: any extension-load failure also prevents SW
  target registration, which is the hard assertion. No change requested.
- **NOTE-3**: AC5 exercises worker startup only (3s settle after
  `Runtime.enable`). There is nothing in a comment-only stub to exercise at
  idle-wakeup; this becomes relevant only when 2.2+ adds real worker code,
  at which point the harness should be extended to trigger and observe
  wakeups.
- **NOTE-4**: The test's forbidden-token list checks `fetch(` call form
  only; a bare `fetch` reference without a call would slip past that one
  assertion — but the exact-equality assertion on comment-stripped code
  (`["'use strict';"]`) already makes any such token impossible. Defense in
  depth is fine as-is.

## Conclusion

Task 2.1 implements exactly PLAN.md §2.1 and nothing else. The change is
minimal, the stub is genuinely inert, the manifest diff is exactly the
specified block, AC5 is empirically proven (independently re-run by this
reviewer), and the AC7 deferral is honest. No defects found.
**APPROVE.**
